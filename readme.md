# Sentinel

A simple web app. You need **Python** installed.

## Get it running

1. Open a terminal in this folder.
2. Install Flask:

```
pip install flask
```

3. Start the app:

```
python app.py
```

4. Open your browser and go to [http://127.0.0.1:5000](http://127.0.0.1:5000)

That’s it.

## If you change the styling

The look of the site uses Tailwind. You only need this if you edit CSS classes.

1. Install Node.js, then run in another terminal :

```
npm install
npm run build:css
```

Leave that running, then refresh the page to see style changes.
